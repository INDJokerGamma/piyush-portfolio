# Piyush V. Dawkhare - Portfolio Website

This is a personal portfolio website of Piyush V. Dawkhare built with React to showcase experience, projects, skills, and achievements.

## Features

- Responsive design optimized for all devices
- Interactive UI with smooth scrolling
- Project showcase section
- Skills and experience timeline
- Resume download and contact form
- Deployed with GitHub Pages

## Technologies Used

- React.js
- CSS3
- JavaScript
- GitHub Actions for CI/CD
- GitHub Pages for hosting

## Local Development

1. Clone the repository
   ```
   git clone https://github.com/INDJokerGamma/piyush-portfolio.git
   cd piyush-portfolio
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Start the development server
   ```
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Deployment

This portfolio is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the master branch.
